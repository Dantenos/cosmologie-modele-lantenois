# LA THÉORIE DU GOULET — esquisse de synthèse (24/08, nuit)
*Statut : conception. Chaque maillon est étiqueté : [ÉTABLI] physique citable, [CORPUS] démontré
cette campagne, [CONJ] conjecture. Zéro maillon inventé sans nom.*

## L'idée en une phrase
**Un univers hérite d'un seul nombre parce que le cœur de son trou noir parent est un goulet
d'information : l'inflation de masse efface tout — spin, espèces, structure — sauf l'exposant
du flux qui le nourrit.**

## La chaîne
1. Un trou noir astrophysique se forme dans l'univers parent, tournant, nourri par chute
   secondaire : Ṁ_p ∝ v^(β_p−1), avec β_p = 2/(3ε) hérité du spectre du parent. [ÉTABLI :
   Fillmore-Goldreich ; CORPUS : encadrement ε, circularité déclarée]
2. Le flux entrant frappe l'horizon interne → **inflation de masse** : M_local ~ e^(κ₋v) à J fixe,
   donc a/M → 0 (le spin est oublié par gonflement, pas par perte) ; toute matière est traitée
   trans-planckien, et « pas de symétries globales en gravité quantique » efface l'identité
   d'espèce. [ÉTABLI : Poisson-Israel 1990, Ori, Dafermos ; conjecture no-global-symmetries]
   → paie les dettes rotation (9 ordres) et conversion (97 %). *Contrôle chiffrable n°1 :
   κ₋Δv ≳ 25 pour un trou nourri.*
3. À densité de Planck, rebond : nucléation du vide-enfant derrière une **paroi de
   Coleman-De Luccia**, tension σ. La paroi EST le voile — la contrainte tangentielle que
   [K_ab] exige et que la membrane d'horizon ne fournit pas. [ÉTABLI : CDL 1980,
   Blau-Guendelman-Guth 1987 ; CORPUS : membrane ≠ payeur, #115]
   Import assumé : Farhi-Guth-Guven — condition initiale de type trou blanc, à la charge du
   rebond torsionnel (coefficient de Popławski, ouvert). [ÉTABLI comme problème]
4. La dynamique de la paroi (jonction BGG avec σ) fixe l'horloge g(t) : UN paramètre au lieu
   d'un nombre libre ; |κ| < 0,24 devient une borne sur σ. *Contrôle chiffrable n°2 : κ(σ).*
   [CORPUS : dv/dt = 1/(1−x), x₀ ≲ 0,30]
5. Le flux traité traverse ; la réalisation intérieure est une création homogène de masse sans
   pression, Γ = β/t — l'identité exacte du corpus. Homogénéité et pression de création locale
   par construction (lecture A). [CORPUS : identité PC, 5e famille soluble]
6. Loi observable : **w(z) = −β/(3Ht)**, β = β_p·g, mesuré 2,42-2,60 ; croisement z = 0,463 [historique : retiré comme prédiction chiffrée, #111 ; 0,21-0,46 selon β] ;
   attracteur −0,548 ; fin du festin 16-36 Ga. [CORPUS : papier A entier]

## Ce qu'elle prédit, et ce qui la tue
- s = 1 sans liberté (FRB, ~100 sursauts à levier) — vs 0,70 du rival.
- ε ≲ 2×10⁻⁴, profil temporel figé, aucune évasion par annulation.
- β constant, β₁ = −0,43 SI l'hérédité pic tient, κ = κ(σ) — cibles DR3.
- Lecture A obligatoire : toute démonstration que la pression de création n'agit pas
  localement la tue contre les périphéries d'amas déjà publiées.
- Le goulet interdit toute hérédité au-delà d'UN nombre : trouver une SECONDE corrélation
  parent-enfant indépendante de β falsifierait le mécanisme même.

## Ce qu'elle explique que le modèle nu n'expliquait pas
Pourquoi un seul nombre traverse (le goulet, pas seulement le théorème des couches) ; pourquoi
l'intérieur est homogène et sans mémoire ; pourquoi les baryons sont intouchés ; d'où vient la
tension du voile ; pourquoi aucun réglage fin n'est disponible — la rigidité n'est plus une
observation, c'est une conséquence.

## Statut final
Deux contrôles chiffrables, un import déclaré, zéro paramètre ajouté au secteur observable.
Ce n'est pas un résultat : c'est le successeur du papier B, écrit pour celui qui le voudra.
